# 依赖选择

新增核心工具前记录：本次采用已有引擎相同版本的 PyMuPDF 1.25.2（坐标、字体、渲染，AGPL/商业双许可）及 aiohttp 3.14.4（维护中的异步 HTTP 客户端/服务端，Apache-2.0）。
候选：标准库 HTTP 难以正确实现异步 SSE 与背压；Flask 同步代理需额外客户端且长连接占线程；FastAPI 增加不必要框架。
PyMuPDF 优于纯 pypdf 文本匹配，因为需要版式。pytest 仅开发依赖。
独立 .venv、不升级官方环境、仅 localhost、PDF 只本地分析、不写凭据。
风险：PDF 解析资源消耗→限制页数/大小、子进程超时；HTTP 长连接→连接超时/背压；依赖版本漂移→锁定版本。
回退：关闭扩展，运行原入口。独立目录备份后可移走；不需修改官方文件。

# 四入口修复验收（2026-10-11，0.2.0）

初版只拦截 `/translate`，且只支持尾部跳页。实际使用 `/crop-compare` 时没有保护参考文献；文献后有附录时，尾页方案也会回退为全部翻译。此前最小夹具的通过不能代表四个入口已经验收。

## 当前行为

| 入口 | 翻译行为 | 页面与排版 |
| --- | --- | --- |
| `/translate` | 原生引擎只翻译选定正文页 | 保留未翻译文献页；支持原生 Mono / Dual |
| `/crop` | 不调用翻译引擎 | 单栏保留整栏；可靠双栏才分栏 |
| `/compare` | 原文输入时使用相同选页；双语输入不重译 | 保留原生双语任务与下载协议 |
| `/crop-compare` | 原文输入时使用相同选页；双语输入不重译 | 单栏整页左右拼接，避免中线切字 |

页内段落保护未实现，混合页仍翻译。已经翻译的附件不会由新检测自动还原，需要从原文重新执行。扫描/无标题/含糊内容继续翻译。

## 实际验证与范围

- PASS：完整真实论文检测到第 11–14 页为纯参考文献，生成正文范围 `1-10,15-27`；后续附录保留翻译。
- PASS：独立六页夹具来自原文正文、四页文献及一页附录。真实 HTTP 代理、未改写的官方路由与原生引擎使用 SiliconFlowFree 完成四个入口。
- PASS：正文与附录出现中文，四页文献保持英文；原生 Mono 的四页文献渲染像素与原文完全一致。
- PASS：单栏裁剪输出六页，裁剪后拼接输出六页；没有旧中线切割导致的倍页与断行。
- PASS：复用已有真实双语文件形成独立修正版，参考文献双方视图使用原文；27 页保留全部输入文字词项。抽查首页、文献页和附录页的渲染结果。
- PASS：启动器实际启动、健康检查及退出；86 项自动测试，包括并行任务选页隔离。
- UNVERIFIED：本次修改后的 Zotero UI 附件生成尚未重跑；HTTP 任务协议与实际输出已测试，不能据此冒称用户界面验收完成。
- PARTIAL：原生引擎已有的 URI 注释保留限制仍存在。翻译质量、公式理解与所有论文版式不在本次通过结论内。

PDF、完整请求、私人配置和原始服务日志留在本机忽略目录，不随仓库发布。配置测试用私有副本，没有修改用户现有翻译服务设置；四路由真实测试未使用付费服务。

## 实现与回退

独立 `backend_entry.py` 读取原版 Server，在内存中加载原启动流程，并在启动前安装 `backend_adapter`。官方源码文件、引擎源码和 Zotero XPI 不改写；原更新询问仍执行。

适配器把经过有界检测的页码选择附加到每个任务自己的配置，在执行原生引擎时用线程上下文生成 `--pages`。不通过全局变量共享任务选页，不删除输入页面。代理移除客户端自行传入的内部选页字段；后端核对页数与选页边界，并拒绝跳过整份文档。

无兼容性验收或指纹变化时启动原版后端并关闭自动保护；Windows exe 模式的中间选页未验收，会拒绝该选页请求。

更新扩展后需退出旧窗口，再运行 `start.bat`；Zotero 地址保持不变。回退使用 `restore-original.bat`，也可从本机修改前备份恢复扩展；不覆盖 Zotero 原件或已有翻译结果。
